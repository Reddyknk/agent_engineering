# Agent Engineering with Gemini, ADK & Antigravity

This is the Gemini/Google Cloud edition of the Agent Engineering series — the same methodology, case study, and Seven Steps framework as the Claude edition, implemented with Gemini, Google's Agent Development Kit (ADK), and the Antigravity development environment.

- **[`1-Foundations/`](1-Foundations/)** — Book 1: build the bounded WidgetWare SDR Lab application, chapter by chapter, through Chapter 11's engineered loop.
  - **[`1-Foundations/Manuscript/`](1-Foundations/Manuscript/)** — the book itself. Start with `Manuscript/00_README.md`.
  - **[`1-Foundations/Classes/`](1-Foundations/Classes/)** — the instructor-facing course companion: an eleven-class, cumulative program (one class per chapter) with a fixed classroom cadence, verified golden-solution checkpoints, and a three-level homework pattern. Start with `Classes/00_Course_Framework.md`.
  - `1-Foundations/Code/` — reserved for a consolidated final codebase; currently empty.
- **[`2-Enterprise-Agent-Platform/`](2-Enterprise-Agent-Platform/)** — Book 2: extend that application into an enterprise agent platform — memory, enterprise retrieval, adaptive planning, distributed agent collaboration, identity, governance, AgentOps, and continuous evaluation. Start with `2-Enterprise-Agent-Platform/Manuscript/00_README.md`. The manuscript is currently a scaffold; its structure is defined by Book 1's `19_Introduction_to_Book_2.md`. Book 2's own ten-class course companion (one class per chapter, mirroring Book 1's) has not been built yet.

Both books use the same seven-step methodology as every edition of this series — Frame the Use Case, Build Context, Design Agent Capabilities, Build the Harness, Orchestrate Workflows, Engineer Loops, Evaluate & Govern — and the same continuous case study, WidgetWare SDR Lab, with identical business facts (product, ideal customer profile, evidence policy) across both books. Only the implementation technology differs from the Claude edition.
